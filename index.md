# Server Lantern privacy policy

Effective date: October 11, 2026

Server Lantern for Roblox helps a user search public servers in the Roblox experience page they are currently viewing and review possible player matches.

## Information processed

When a user starts a search, Server Lantern processes:

- the Roblox username or user ID entered by the user;
- the current Roblox experience and place identifiers;
- presence information returned by Roblox;
- public server identifiers and player tokens returned by Roblox; and
- Roblox avatar and experience thumbnail URLs.


This information is used only to provide the user-requested server search, display possible matches, and open a server after the user explicitly chooses to join.

## Profile and interface features

Profile tools process public Roblox avatar items, equipped emotes, and community memberships. Private notes are saved only in Chrome local extension storage and are not transmitted to Roblox, RoValra, or the publisher. Shared profile-view tracking is not included.

## Data transmission

Region discovery and server metadata requests send the current place ID, selected region, and public server IDs to https://apis.rovalra.com over HTTPS without Roblox cookies. RoValra receives ordinary network information such as the request IP address. These requests retrieve region counts, locations, and server metadata; search usernames and private notes are not included.

Search requests are sent directly from the user's browser to Roblox services over HTTPS. Roblox may attach the user's existing Roblox sign-in session to authenticated requests. Server Lantern does not read, copy, or store the user's password or Roblox cookie values.

Server Lantern does not send search targets, results, browsing activity, or Roblox account information to the extension publisher. It contains no advertising, analytics, or publisher-operated tracking service.


## Local storage and retention

The extension stores notice acceptance and optional interface preferences (sidebar spacing, collapsed state, hidden sidebar links, game-card shortcuts, and server-card enhancements) locally in Chrome. Updating to version 3.11.0 removes legacy license keys, activation state, and trial counters. Selected player search history, pinned profiles, recently visited experiences, private-server favorites and recents, preferred server regions, presets, and private profile notes are stored locally until removed or the extension is uninstalled. Temporary API and scan caches remain in memory. No purchase or activation is required in version 3.16.3.

Users can erase the locally stored acceptance setting by removing the extension or clearing the extension's stored data in Chrome.

## Sharing

Data needed for player searches and public profile features is shared with Roblox. Place IDs, region selections, and public server IDs are shared with RoValra to retrieve region and server metadata. Server Lantern does not sell user data or share it with advertisers, data brokers, or unrelated third parties.

## Limited use

Server Lantern uses information only to provide and maintain its disclosed single purpose. It does not use or transfer data for personalized advertising, credit decisions, or unrelated purposes, and it does not permit humans to read user data except when the user explicitly provides information for support or when required by law or security needs.

## Children

Server Lantern does not knowingly collect personal information on behalf of its publisher. Roblox users should use the extension only with any consent required by their local law and household rules.

## Introductory access and planned premium search

Version 3.16.3 provides free introductory access without an enforced trial timer, search quota, payment processing, or license activation. Premium-only search is planned for a future release. Pricing, timing, and limits have not yet been announced. This policy describes the current release; any future payment or activation service, related data handling, and access requirements will be disclosed before introduction.

## Changes and contact

Material changes to these practices will be disclosed before the changed handling begins. For privacy questions, contact the publisher through the support email shown on Server Lantern's Chrome Web Store listing.

Server Lantern is an independent extension and is not affiliated with or endorsed by Roblox Corporation.
