# Server Lantern privacy policy

Effective date: September 5, 2026

Server Lantern for Roblox helps a user search public servers in the Roblox experience page they are currently viewing and review possible player matches.

## Information processed

When a user starts a search, Server Lantern processes:

- the Roblox username or user ID entered by the user;
- the current Roblox experience and place identifiers;
- presence information returned by Roblox;
- public server identifiers and player tokens returned by Roblox; and
- Roblox avatar and experience thumbnail URLs.

If the user purchases or activates a license, Server Lantern also processes the license key.

This information is used only to provide the user-requested server search, display possible matches, and open a server after the user explicitly chooses to join.

## Data transmission

Search requests are sent directly from the user's browser to Roblox services over HTTPS. Roblox may attach the user's existing Roblox sign-in session to authenticated requests. Server Lantern does not read, copy, or store the user's password or Roblox cookie values.

Server Lantern does not send search targets, results, browsing activity, or Roblox account information to the extension publisher. It contains no advertising, analytics, or publisher-operated tracking service.

License purchases are completed on Gumroad's checkout. Gumroad processes the purchaser's payment and contact information under its own privacy policy. During activation and periodic validation, the extension sends the entered license key and the product identifier to Gumroad over HTTPS. Roblox search information is not included in those requests.

## Local storage and retention

The extension stores whether the user accepted its in-product data notice, the number of free searches used, and, after activation, the license key, provider name, and last validation time. Search targets, public server results, avatar matches, and scan caches remain in memory for the active page and are discarded when the page or extension context closes.

Users can erase the locally stored acceptance setting by removing the extension or clearing the extension's stored data in Chrome.

## Sharing

Data needed for a search is shared only with Roblox because Roblox provides the account, presence, server, and thumbnail services required by the extension. Server Lantern does not sell user data or share it with advertisers, data brokers, or unrelated third parties.

## Limited use

Server Lantern uses information only to provide and maintain its disclosed single purpose. It does not use or transfer data for personalized advertising, credit decisions, or unrelated purposes, and it does not permit humans to read user data except when the user explicitly provides information for support or when required by law or security needs.

## Children

Server Lantern does not knowingly collect personal information on behalf of its publisher. Roblox users should use the extension only with any consent required by their local law and household rules.

## Changes and contact

Material changes to these practices will be disclosed before the changed handling begins. For privacy questions, contact the publisher through the support email shown on Server Lantern's Chrome Web Store listing.

Server Lantern is an independent extension and is not affiliated with or endorsed by Roblox Corporation.
